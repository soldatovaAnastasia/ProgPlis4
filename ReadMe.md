# Лабораторная работа №4

## Разработка контроллера 7-сегментного индикатора на ПЛИС

### Цель работы

Целью лабораторной работы является получение практических навыков разработки
цифровых устройств для ПЛИС, их проверки при помощи моделирования и запуска
на учебном стенде.

В ходе выполнения работы необходимо:

- освоить работу с проектом в среде Gowin EDA;
- научиться назначать порты модуля на выводы ПЛИС с помощью файла `.cst`;
- освоить формирование тактовых сигналов при помощи делителя частоты;
- получить практический опыт последовательной передачи данных в сдвиговые регистры;
- реализовать динамическую индикацию на 7-сегментных индикаторах;
- научиться обрабатывать сигналы механических кнопок;
- научиться проверять проект в симуляции перед загрузкой в ПЛИС;
- проверить работу разработанного устройства на стенде.

## Общие сведения

На стенде расположены два 4-разрядных 7-сегментных индикатора. Управление
индикаторами осуществляется при помощи двух последовательно соединённых
8-битных сдвиговых регистров.

Для каждого разряда индикатора используется 8 бит: 7 бит задают состояние
сегментов, а восьмой бит — состояние точки. Положение активного разряда также
кодируется 8 битами. Таким образом, полное обновление одного разряда
передаётся пакетом из 16 бит. За один полный цикл должны быть обновлены все
восемь разрядов.

Схему подключения индикаторов и сдвиговых регистров можно найти в
документации к стенду.

В качестве источника тактового сигнала используется кварцевый генератор
27 МГц, расположенный на плате с ПЛИС. Для формирования тактового сигнала
сдвигового регистра необходимо использовать делитель частоты. Частота должна
быть достаточно низкой для корректной работы сдвигового регистра и
достаточно высокой, чтобы мерцание индикатора не было заметно.

# Часть 1. Контроллер вывода на 7-сегментный индикатор

## Задание

Необходимо реализовать на ПЛИС контроллер последовательного вывода
28-битного значения `display_value` в десятичном виде на два 4-разрядных
7-сегментных индикатора.

После полного обновления всех восьми разрядов контроллер должен формировать
импульс готовности и подавать его на вывод ПЛИС `R1`.

## Требования к реализации

1. Назвать верхнеуровневый модуль `top`.
2. Модуль должен иметь 28-битный вход `display_value` — выводимое значение.
   Остальные порты (тактовый сигнал, данные, тактовый сигнал и сигнал
   защёлкивания сдвиговых регистров, импульс готовности) могут называться
   произвольно.
3. Добавить в директорию `gw_prj/src/` файл распиновки `.cst`, в котором
   порты модуля назначены на соответствующие выводы ПЛИС стенда. По этому
   файлу testbench определяет назначение ваших сигналов — при неправильной
   распиновке решение не пройдёт проверку.
4. Использовать кварцевый генератор 27 МГц как источник тактового сигнала.
5. Тактовый сигнал сдвиговых регистров формировать делителем частоты.
6. **Не использовать операцию деления** для разделения значения на разряды.

## Порядок проверки

1. После подачи питания контроллер должен начать передачу данных на
   сдвиговые регистры.
2. Значение `display_value` должно корректно отображаться на всех восьми
   разрядах.
3. Последовательность сигналов должна обеспечивать передачу двух 8-битных
   слов для каждого разряда.
4. После обновления восьмого разряда должен формироваться импульс готовности.
5. При изменении `display_value` новый набор разрядов должен быть выведен
   без смешивания данных с предыдущим набором.

В симуляции проверяется совпадение отображаемых сегментов для всех восьми
разрядов и нескольких последовательных значений `display_value`.

# Часть 2. Модификация контроллера вывода

## Задание

Необходимо реализовать на ПЛИС модификацию контроллера: устройство,
формирующее значение в соответствии с типом задания вашего варианта, выводящее
его на два 4-разрядных 7-сегментных индикатора и управляемое кнопками.

Чтобы получить допуск к стенду, необходимо написать код, промоделировать его
и добавить изображение с временными диаграммами в ваш репозиторий.

## Значения варианта

| Параметр | Значение |
|---|---|
| Тип задания | STOPWATCH |
| Начальное значение / порог индикации | 35640000 |
| Период изменения | 4 с |
| Шаг / Количество триггеров | 4 |
| Режим индикации | DECIMAL_ZERO |
| Кнопка S0 | выключение дисплея / включение дисплея |
| Кнопка S1 | остановка изменения значения / продолжение изменения |
| Кнопка S2 | сброс / возврат к начальному состоянию |

Неиспользуемые кнопки необходимо оставить без функции.

## Тип задания

Реализовать секундомер. Пороговое значение — 35640000 милисек. Каждые 4 сек значение увеличивается на 4. В дополнение к отображению формат вывода на дисплей должен быть таким - HH.MM.SS.mSmS, где HH — часы, MM — минуты, SS — секунды, mSmS — миллисекунды. 

## Управление кнопками

- **S0** — выключение дисплея / включение дисплея.
- **S1** — остановка изменения значения / продолжение изменения.
- **S2** — сброс / возврат к начальному состоянию.

При обработке кнопок необходимо учитывать, что механическая кнопка
может формировать несколько переключений при одном нажатии.
Необходимо обеспечить корректное распознавание нажатия кнопки.

Одновременное нажатие нескольких кнопок не является частью задания,
если иное явно не указано в варианте.

## Условие управления светодиодом

Светодиод должен быть включён, когда значение секундомера больше или равно35640000.

Светодиод должен изменять своё состояние в соответствии с указанным
условием во время работы устройства.

## Требования к реализации

1. Использовать кварцевый генератор 27 МГц как источник тактового сигнала.
2. Создать делитель частоты для формирования необходимых тактовых сигналов.
3. Реализовать управление двумя 4-разрядными 7-сегментными индикаторами.
4. Передавать данные на индикатор через два сдвиговых регистра.
5. Обеспечить динамическую индикацию всех восьми разрядов.
6. Использовать 8 бит для кодирования сегментов одного разряда.
7. Использовать 8 бит для выбора активного разряда.
8. **Не использовать операцию деления** — ни для разделения на разряды, ни,
   например, для реализации формата часов.
9. Реализовать обработку назначенных кнопок.
10. Реализовать условие управления светодиодом.
11. Для данного варианта необходимо использовать режим индикации «DECIMAL_ZERO».

## Порядок проверки

1. После подачи питания устройство должно перейти в начальное состояние,
   указанное в варианте.
2. Значение должно отображаться на 8-разрядном 7-сегментном индикаторе
   в соответствии с выбранным режимом индикации.
3. При выполнении заданного условия должен включаться светодиод.
4. Нажатие назначенных кнопок должно приводить к соответствующим изменениям
   состояния устройства.
5. При необходимости проверить работу сигналов сдвигового регистра
   с помощью логического анализатора.
